I never learned things in order — I learned them by needing them.

Somewhere along the way that turned into an operating system, because I wanted a computer that actually listened to me instead of the other way around. Then an AI, because the OS needed a mind. Then a browser, a window manager, a file manager, a CNC machine that draws equations from a Telegram message — each one starting the same way: something didn't exist the way I wanted it to, so I stopped waiting and built it.

I live at the intersection of hardware and software — Arch Linux, embedded chips, and language models — and most of what you'll find here is the record of me teaching myself things a syllabus never got around to.

### 🚀 A Few I'm Proud Of

**[Marin_OS](https://github.com/BayazidHabibSiddikee/Marin_OS)** — My first real system: a Debian-based OS where an AI is the owner, not the assistant. The project that taught me controlling a computer with code is only the beginning.

**[Marin_Kitagawa_v3](https://github.com/BayazidHabibSiddikee/Marin_Kitagawa_v3)** — FastAPI + LangChain + ChromaDB with VRM model support. My daily driver, still actively maintained. The one that started all the others.

**[SwordFish](https://github.com/BayazidHabibSiddikee/SwordFish)** — A browser built for researchers, not casual scrolling: PDFs, docs, spreadsheets, video downloads, sandboxed IP switching. Built because nothing off-the-shelf worked the way I needed it to.

**[CNC Math Plotter](https://github.com/BayazidHabibSiddikee/CNC-Math-Plotter)** — Write an equation in plain text, send it over Telegram, watch a machine draw it. A physical Desmos.

**[SwordWM](https://github.com/BayazidHabibSiddikee/SwordWM)** — My own window manager. Not because the defaults are bad — they're not — but because I wanted mine.

**[web_based_terminal](https://github.com/BayazidHabibSiddikee/web_based_terminal)** — Flashing ATmega chips from a browser, no desktop IDE required, built so my friends could stop fighting the Arduino IDE.

**[SwordFM](https://github.com/BayazidHabibSiddikee/SwordFM) + [SwordFM_Android](https://github.com/BayazidHabibSiddikee/SwordFM_Android)** — A C++ file manager themed for SwordDeck, paired with an Android file manager that currently only shares files over webservice. Next step: merge the two into one cross-platform app with proper Bluetooth file sharing between them.

**[Fluidsim-Linux](https://github.com/BayazidHabibSiddikee/Fluidsim-Linux)** — Mechatronics work keeps pulling me back to Windows for fluid simulation software. Rebuilding a lightweight version so Linux doesn't have to be the compromise.
